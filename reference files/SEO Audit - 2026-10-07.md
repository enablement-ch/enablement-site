# Enablement.ch SEO audit

Date: 2026-10-07

## Scope and result

Audited every generated page: 31 HTML pages, including 23 public indexable pages and 8 intentionally excluded previews or confirmation pages. `npm run build` followed by `npm run audit:seo` passes. The audit checks unique titles and descriptions, canonical URLs, primary headings, sitemap consistency, JSON-LD parsing, image alt attributes and local assets, internal links, and fragment targets.

These are technical eligibility and discoverability checks. They do not measure Google rankings, traffic, actual index coverage, or field Core Web Vitals.

## Fixes shipped

- Included the public LinkedIn Competitor Analysis landing page in the sitemap. Personal report routes remain excluded.
- Added a clear search title, description, and visible introduction for the free LinkedIn competitor analysis.
- Added shorter, descriptive metadata for the six current customer stories while preserving their visible outcome headlines and evidence.
- Gave Privacy and GTC their own descriptions instead of the generic outbound service description.
- Added Organization, WebSite, WebPage or CollectionPage, BreadcrumbList, and service-specific Service JSON-LD using existing public information. No invented ratings, customer reviews, locations, or prices.
- Used absolute image URLs and image metadata for social previews.
- Preserved canonical URLs on www.enablement.ch, without query parameters or trailing slashes.
- Retained noindex on previews and confirmations, with follow so links can still be discovered.
- Corrected the legacy case-study redirects. The six older customer stories now resolve to their existing story pages instead of nonexistent customer-results pages.
- Added links to those six older stories from the current Customer Results index so they are reachable from the public navigation.
- Linked the AI Sales Coach resource to the related AI Revenue Operations service.
- Moved the Facebook noscript tracking image out of the document head and gave it an empty decorative alt attribute.
- Added image dimensions and deferred loading to footer founder photos. Gilbert's new photo has a new URL to avoid the previous asset cache.

## Run again

